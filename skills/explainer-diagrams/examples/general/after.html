How a pull request gets merged

Five states, one return path, one exit.

changes requested
Openbranch pushed, PR created
Reviewa reviewer reads the diff
Approveat least one approval, checks green
Mergesquash or rebase onto main
Closed without merge reviewer or author closes it, no merge
One loop, one exit.

A PR either goes around the review loop again or it merges. Nothing else is a state.
